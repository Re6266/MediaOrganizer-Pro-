## 一、本周工作进展

本周小组在前两周完成项目基础框架、数据库设计、本地媒体扫描和元数据提取的基础上，开始推进媒体重复与相似素材识别模块。围绕项目提出的分级式媒体冗余识别目标，完成算法实现、数据存储及测试验证，并开展模块间接口衔接，为后续照片浏览、分组管理和智能选片功能提供基础。

1. **完成重复文件检测算法实现。** 由张璐负责主要代码开发，采用 SHA-256 哈希算法计算文件内容摘要，通过比较哈希值识别内容完全一致的文件。实现 `modules/duplicate_detector.py`，支持批量检测和重复文件分组，并记录文件对应的哈希信息。任昕洁参与技术方案讨论，检查该方法与项目分级式媒体识别目标的匹配情况。

2. **完成视觉相似图片检测算法。** 由张璐完成 pHash 感知哈希算法的实现，通过灰度转换、图像缩放、离散余弦变换（DCT）和哈希编码提取图片特征，再利用汉明距离衡量图片之间的视觉差异。实现 `modules/similarity_detector.py`，支持设置检测阈值并输出相似图片对。经过测试调整，当前测试使用的汉明距离阈值为 15。李馨瑶结合第二周扫描模块提供的媒体数据结构，对算法输入路径及后续数据读取方式进行了衔接检查。

3. **完成相似图片自动分组。** 由张璐实现 `modules/similarity_group.py`，采用并查集算法，根据相似图片之间的关联关系自动合并候选照片组。例如，A 与 B 相似、B 与 C 相似时，可以将三张图片归入同一组。任昕洁参与分组逻辑和模块接口讨论，孙昊然结合后续照片组展示需求，对分组结果的数据组织方式进行检查，为第四周页面开发做好准备。

1. **自动测试：** 在 Windows 本机运行 `python -m unittest discover -s tests -p "test_week3.py" -v`，四项测试全部通过。测试内容包括：

   - 相似图片检测：验证存在轻微视觉差异的图片能够在设定阈值下被识别；
   - 相似图片分组：验证多组图片之间的关联关系能够通过并查集正确合并。

2. **数据库验证：** 已执行检测结果数据表初始化、检测结果保存和读取操作，完成重复检测与相似检测结果的数据库存储流程验证，为后续页面读取检测结果提供基础。

3. **人工测试：** 使用项目测试图片进行检测，能够区分完全重复文件与视觉相似图片。通过调整 pHash 汉明距离阈值，可以改变相似图片的检测范围。当前阈值 15 为测试使用参数，尚未通过大规模数据集验证其最优性。

4. **当前存在的问题：** SHA-256 只能识别内容完全一致的文件，无法识别经过压缩、缩放或编辑后的图片；pHash 能够识别视觉特征接近的图片，但不能单独判断图片是否属于同一拍摄场景。对于连续拍摄、背景相似或人物动作差异较大的照片，仍需结合拍摄时间、图像质量及人工判断进一步分析。

5. **模块集成尚未完成：** 本周主要完成算法、分组和数据库存储功能，尚未形成完整的前端交互流程。检测结果展示、用户手动调整分组及后续智能选片功能仍需在下一阶段继续开发。

## 三、本周关键决策及理由

1. **采用 SHA-256 与 pHash 相结合的分级检测方案。** SHA-256 用于识别内容完全一致的文件，pHash 用于识别视觉上接近但文件内容不同的图片。两种方法分别处理不同层次的媒体冗余问题，避免将完全重复与视觉相似混为一谈。

2. **采用汉明距离作为相似程度判断依据。** pHash 通过生成固定长度的感知哈希值，再计算不同哈希值之间的汉明距离衡量视觉差异。保留可调整的阈值参数，方便后续根据实际测试数据优化检测范围。

3. **使用并查集实现相似图片分组。** 单纯输出相似图片对难以形成完整的照片组，因此采用并查集处理图片之间的关联关系，将存在间接关联的图片合并为候选组，为后续照片组管理提供基础。

4. **沿用原有项目数据库和模块结构。** 保留第一周和第二周已完成的基础文件，在原有数据库基础上增加检测结果相关数据表，减少对媒体扫描、元数据提取及原有索引功能的影响。

5. **将算法处理与前端展示分开开发。** 本周优先保证检测算法、分组逻辑和数据库存储能够独立运行，后续由相关成员开展页面集成，降低算法逻辑与前端交互之间的耦合程度。

6. **采用集中实现与交叉检查相结合的协作方式。** 本周由张璐负责主要算法代码实现，其他成员分别承担总体方案协调、原有模块衔接、数据结构检查和后续页面需求梳理，并通过测试结果共同确认阶段性成果，以提高开发效率和模块兼容性。
